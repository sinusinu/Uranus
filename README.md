# Uranus

![Icon](app/src/main/ic_launcher-playstore.png)

A file-picking music player

# Features

- SAF-based, File-picking playlist system
- A bunch of weird features, including:
  - Volume multiplier
  - Sleep timer
  - Playback speed modifier
